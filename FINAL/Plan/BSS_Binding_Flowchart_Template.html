BSS System Lifecycle Flowchart

Step-by-Step Binding Sequence from Account Creation to Gate Pass & Letter Issuance

1

Create Employer Account & Site Setup

Principal Employer registers organization account (BSS-E) and creates a new construction or plant Site Master.

📌 Output: Site Master created & Site QR Code generated
Employer
2

Create Contractor Account

Contractor registers company profile (BSS-C) on the portal to get a Contractor ID and master QR code.

📌 Output: Contractor Profile activated
Contractor
3

Link Contractor & Employer (Contractor Scans Employer QR)

Contractor scans Employer's QR code to send engagement request. Employer receives alert and accepts the request.

📌 Output: Contractor ↔ Employer linkage active
Contractor Employer
4

Employer Allots Site & Contractor Accepts

Employer allots the specific active site to the Contractor. Contractor accepts the site allotment terms.

📌 Output: Site Allotment authorized for deployment
Employer Contractor
5

Create Worker Account & eKYC

Worker registers on BSS Worker mobile app or web, completing profile setup and Aadhaar eKYC linkage.

📌 Output: BSS Worker ID & Dynamic Worker QR generated
Worker
6

Contractor Scans Worker QR & Binding Approved

Contractor scans Worker's QR code to initiate binding. Worker approves request via OTP/app prompt to complete link.

📌 Output: Worker ↔ Contractor ↔ Employer 3-way binding completed
Contractor Worker
7

System Output: Letters & Gate Passes Generated

System Output

With 3-way binding completed, the system populates BSS data tokens to issue official letters and gate passes.

📄 Binding & Unbinding Letters

Generated with dynamic tokens (Worker name, Contractor details, Employer name, timestamps).

🎫 Gate Passes (Employer Issued)

Temporary and Permanent Gate Passes generated exclusively by Employer with site validity limits.
