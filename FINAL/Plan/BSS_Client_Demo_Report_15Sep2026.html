How the data flows

LayerTechnologyRole
BrowserNext.js 16 App Router (React)Portal UI, session cookie, server components
ProxyNext.js Route Handlers /api/*Holds the encrypted session cookie; forwards to Django

DataPostgreSQL 16Workers, bindings, attendance, wages, benefits, grievances…
Authentication: the browser authenticates with mobile + OTP, MPIN, or password. The Next.js layer stores an AES‑GCM encrypted, httpOnly __Host-bss_session cookie. Django accepts either a JWT Bearer token or the trusted X-BSS-Subject header. The registered mobile is the login identity and is locked on every role (cannot be edited anywhere).
